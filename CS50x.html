0.0 Algorithms: Correctness Versus Efficiency

Computing takes an input and processes it through an algorithm—a finite, step-by-step sequence of instructions—to produce an output. Multiple algorithms can solve the same problem, so computer scientists evaluate them on two axes: correctness (does it reliably yield the right result?) and efficiency (how well does it minimise time and effort?).

Approach A · Page-by-Page (Linear) 
1  pick up phone book
2  open to first page of phone book
3  look at names
4  if "Smith" is among names
5      call Mike
6  else if not at end of book
7      flip to next page
8      go to line 3
9  else
10     give up

Correct, yet slow: doubling a 500-page book adds up to 500 extra steps (even flipping two pages at a time remains linear).

Approach B · Halving the Book (Binary) 
1  pick up phone book
2  open to middle of phone book
3  look at names
4  if "Smith" is among names
5      call Mike
6  else if "Smith" is earlier in book
7      open to middle of left half
8      go to line 3
9  else if "Smith" is later in book
10     open to middle of right half
11     go to line 3
12 else
13     give up

Doubling a 500-page sorted phone book adds only 1 single step because each check eliminates half of the remaining pages.

0.1 & 0.2 Binary Numbers and ASCII Character Encoding

Every number system has a base—the count of possible values per digit. Humans commonly use decimal (base 10, digits 0–9, place values $10^0, 10^1, 10^2$). Computers store data as bits (binary digits, base 2, values 0 and 1), where each column represents a power of 2 ($1, 2, 4, 8, 16, 32, \dots$). For instance, binary 110 equals $(1 \times 4) + (1 \times 2) + (0 \times 1) = 6$.

To store text, computers rely on a consistent character encoding standard called ASCII. Original 7-bit ASCII encodes $2^7 = 128$ characters (extended 8-bit ASCII encodes 256). Capital 'A' is 65 (1000001) and lowercase 'a' is 97 (1100001). Notice that lowercase letters are always 32 greater than their uppercase counterparts—switching case requires flipping only the single bit in the 32s place! Because 256 values cannot capture mathematical symbols or global scripts, Unicode extends the standard to over 1 million characters whilst keeping its first 128 codes identical to ASCII.

0.3 & 0.4 Pseudocode and Visual Programming in Scratch

Before writing formal syntax, computer scientists express logic in pseudocode—structured natural language using assignment (e.g., let n = 0) and indentation to bind statements inside loops and conditions. Scratch translates these exact constructs into snap-together graphical blocks without syntax errors: programs begin on "When green flag clicked", act upon objects called sprites, evaluate hexagonal sensing or boolean conditions (if ... then, and, or), and repeat instructions via repeat, repeat until, or forever loops.

1.7 & 1.8 C Syntax, Compilation, and Variables

C requires strict syntax: statements end with semicolons (;), blocks sit inside curly braces ({ }), and execution begins at int main(void). Preprocessor directives such as #include <stdio.h> import header files so functions like printf() are available. Because CPUs execute only 0s and 1s, source files (hello.c) must be compiled into machine object code using make hello (which invokes clang) and run via ./hello.

A variable is a typed storage container declared with a type and name (e.g., int count = 2;). Using #include <cs50.h> provides input helpers like get_int("Integer please: "), whose value can be formatted into strings via placeholders such as %i.

1.1 Native and CS50 Library Data Types

Unlike dynamically-typed languages that infer types at runtime, C is statically-typed: every variable's type must be declared up front. Type qualifiers modify storage bounds: unsigned removes negative values (shifting an int from $[-2^{31}, 2^{31}-1]$ to $[0, 2^{32}-1]$), while long long expands capacity to 8 bytes ($[-2^{63}, 2^{63}-1]$).

1.0, 1.4 & 1.5 Boolean Expressions, Operators, and Loops

C evaluates conditions using comparison operators (<, >, ==, <=, >=, !=) and logical operators (&& AND, || OR, ! NOT) across if / else if / else branches, switch statements (requiring break; between cases), and the ternary operator (x > 3) ? 2 : 1.

Arithmetic operators (+, -, *, /, and modulus % for remainder) follow strict type rules: dividing two integers (10 / 3) truncates the decimal to 3, whereas 10.0 / 3.0 yields a floating-point result. Assignment shorthands include +=, -=, *=, /=, ++, and --.

Loops in C · For, While & Do-While 
// For loop: known iteration count
for (int i = 0; i < 10; i++)
{
    printf("hello!\n");
}

// While loop: condition checked first
int k = 0;
while (k < 10)
{
    printf("%i\n", k);
    k++;
}

// Do-while: runs at least once (input validation)
int j;
do
{
    j = get_int("Positive Number: ");
}
while (j <= 0);
1.2 & 1.3 Functions, Scope & Libraries

Functions provide abstraction: callers specify inputs and receive a return value (or void with a printed side-effect) without needing internal details. Variables inside functions have local scope; variables outside all functions have global scope (accessible everywhere, yet harder to track).

  • <ctype.h>: isalpha(), isdigit(), islower(), isupper(), tolower(), toupper()
  • <math.h>: ceil(), floor(), pow(), lround(), log2()
  • <string.h>: strlen(), strcmp(), strstr()
  • <stdlib.h>: atoi(), rand(), srand()

1.6 Principles of Good Design

Well-designed code is robust, consistent, modular, and non-repetitive. Avoid magic numbers (unexplained hard-coded constants) by naming them with #define at the top of the file. Replace chained standalone if statements with else if or switch so the computer stops checking once a match is found. Finally, remember that design involves tradeoffs: a compact for loop over an array int boxes[] = {12, 10, 3, 1} avoids repetition compared with writing four sequential division/modulo blocks, though programmers may debate readability versus conciseness.

Section 03 · Week 2 · Arrays & Tooling

Arrays, Strings, debug50, CLI Arguments & Linking

2.0 Arrays & Strings 2.1 Debugging 2.2 Command-Line Interaction 2.3 Compiling 2.4 Exit Codes 2.5 Typecasting

An array stores multiple values of the same data type contiguously in memory, indexed from 0 up to size - 1 (e.g., int ages[5]; ages[0] = 28;). In C, a string is simply an array of char values ending with the null-terminator '\0' so functions like strlen() know where the text ends.

2.1 Bugs & debug50

When programs exhibit unexpected behaviour (bugs), a graphical debugger (debug50 ./program_name) pauses execution at a red-dot breakpoint so you can step over blocks, step into functions line by line, step out, or clear breakpoints.

2.3–2.5 Compiling, Exit Codes & Typecasting

make orchestrates clang and the linker, combining object code from multiple files and libraries (such as cs50.h) into one executable. Returning 0 from main signals success; non-zero exit codes (1, -1) denote validation errors. Typecasting converts types (e.g., implicit cast float d = 28.523; int e = d; becomes 28).

2.2 Command-Line Interaction: argc and argv

Instead of prompting mid-run, C programs can accept command-line arguments via int main(int argc, string argv[]). argc (argument count) counts space-separated tokens including the invocation itself, while argv (argument vector) is the zero-indexed array of argument strings.

Section 04 · Week 3 · Algorithms & Theory

Searching, Sorting, Recursion, Big O & Unsolvable Problems

3.0 Algorithms 3.1 Binary Search 3.2 Bubble Sort 3.3 Complexity 3.4 Insertion Sort 3.5 Linear Search 3.6 Merge Sort 3.7 Recursion 3.8 Selection Sort

Computational complexity measures how an algorithm's runtime or memory scales as input size $n$ grows. Big $O$ captures the upper bound (worst-case order of growth, dropping constants and lower-order terms), while Big $\Omega$ captures the lower bound (best-case runtime).

Algorithm Core Mechanism Big $O$ (Worst) Big $\Omega$ (Best)
Linear SearchChecks every element sequentially from index 0; works on unsorted lists.O(n)Ω(1)
Binary SearchHalves a sorted array using min, middle, and max indices.O(log n)Ω(1)
Bubble SortCompares adjacent pairs and swaps out-of-order elements so large values bubble up.O(n²)Ω(n)
Insertion SortSplits array into sorted/unsorted parts; inserts elements into place (fast if nearly sorted).O(n²)Ω(n)
Selection SortRepeatedly finds the minimum element to minimise total swaps (still $O(n^2)$ comparisons).O(n²)Ω(n²)
Merge SortUses recursion to split subarrays and merge them in sorted order.O(n log n)Ω(n log n)

3.7 Recursion & Unsolvable Problems (The Halting Problem)

In a recursive solution, a function invokes a slightly modified instance of itself ("passing the buck") until reaching a base case, yielding elegant algorithms such as Merge Sort. Even so, some tasks are provably unsolvable problems. By contradiction (the Halting Problem), no universal programme can accept any arbitrary programme and sample input and definitively determine whether that programme will halt or get stuck in an infinite loop—because a wrapping function could always negate the detector's answer.

4.0–4.3 Hexadecimal, Images, and File I/O

Long strings of binary bits are cumbersome, so computer scientists group 4 bits at a time into hexadecimal (base 16, digits 0–9 and A–F; e.g., binary 1111 = decimal 15 = hex F). Images are files of bytes representing grids of pixels across formats such as .bmp, .jpg (lossy), and .png (lossless).

To persist data beyond a programme's execution, C uses File I/O via a FILE * pointer opened with fopen(filename, mode), manipulated, and closed with fclose(). Related fields (such as a student's name, age, and GPA) can be encapsulated inside custom data structures.

5.0–5.2 Abstract Data Structures

  • Stack (LIFO): Last In, First Out—like a stack of kitchen plates. push() inserts at the head; pop() removes from the head; top() inspects it.
  • Queue (FIFO): First In, First Out—like a grocery checkout line. enqueue() adds to the back; dequeue() removes from the front.
  • Hash Table: Maps keys to buckets so key–value pairs can be accessed in average constant time $O(1)$.
  • Graphs & Tries: Nodes connected by edges (graphs/trees); Tries branch character-by-character for rapid dictionary lookup.

          6.0 Python vs C
          

            Python is a high-level, dynamically-typed language interpreted at runtime (python hello.py) that abstracts away manual memory management. Instead of curly braces and semicolons, Python uses colons (:) and indentation. + performs arithmetic addition on numbers or concatenation on strings; input() always returns a string.
          

          
mylist = ["foo", "bar"]   # ordered, mutable
mylist.append("baz")
mytuple = ("foo", "bar")  # ordered, unchangeable
fruit = {"apple": 3, "lime": 10}  # dict key-value
for idx, val in enumerate(mylist):
    print(idx, val)

        

        

          7.0 Relational Databases & SQL
          

            Databases store persistent data in spreadsheet-like tables composed of typed fields (columns: INTEGER, TEXT, REAL, BLOB, DATETIME, NULL, NUMERIC) and records (rows). Each table has one unique primary key (often AUTOINCREMENT) so tables can be linked cleanly.
          

          
CREATE TABLE 'dogs' ('id' INTEGER PRIMARY KEY AUTOINCREMENT NOT NULL, 'name' TEXT, 'age' INTEGER, 'favorite food' TEXT);
INSERT INTO "dogs" ("name", "age", "favorite food") VALUES ("Willow", 4, "watermelon");
SELECT * FROM "dogs";
UPDATE "dogs" SET "age" = 2 WHERE id = 4;
DELETE FROM "dogs" WHERE id = 4;

8.0–8.8 Internet Protocols & HTTP

      

        Devices communicate online using layered protocols: DHCP assigns each device an IP address; DNS translates human-readable domain names into IP addresses; and TCP/IP splits messages into packets and guarantees reliable delivery. On top of TCP/IP, web browsers (clients) exchange messages with web servers using HTTP: GET requests retrieve pages, while POST requests transmit form payloads. Servers answer with a numeric status code.

    •

11.0–11.3 Computers, CPU Cycle, and Memory Hierarchy

          

            A computer combines physical hardware and virtual software (applications communicating with the operating system). Its central processing unit (CPU) contains billions of microscopic transistors executing four repeating phases: fetch instructions from memory, decode them, execute the calculation, and store the result. Computers balance speed and capacity across fast volatile RAM and persistent storage (HDD / SSD).
          

        

        

          
12.0–14.1 Routers, Multimedia, and Cybersecurity

          

            Across the Internet, routers consult routing tables to direct packets of data across interconnected networks to their destinations. In multimedia, Virtual Reality (VR) and Augmented Reality (AR) immerse or overlay digital graphics onto the physical world. Finally, cybersecurity and trust models establish how systems authenticate users, verify integrity, and protect data against adversaries.
